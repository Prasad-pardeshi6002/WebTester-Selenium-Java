

**# WebTester - Selenium Automation with Java and Spring Boot**



**## Project Overview**

**WebTester is a web-based website testing application developed using Java, Spring Boot and Selenium WebDriver.**



**It provides a web interface to execute website testing operations and view test results and testing history.**



**## Technologies Used**

**- Java 21**

**- Spring Boot**

**- Selenium WebDriver**

**- Maven**

**- Thymeleaf**

**- HTML and CSS**

**- H2 Database**



**## Features**

**- Web-based testing interface**

**- Selenium WebDriver integration**

**- Automated browser testing**

**- Test execution management**

**- Test results display**

**- Testing history**



**## Project Structure**

**- Controller: Handles web requests**

**- Service: Handles application logic**

**- Engine: Manages test execution**

**- Repository: Database operations**

**- Templates: HTML user interface**

**## How to Run**



**1. Clone the repository:**



&#x20;  **git clone https://github.com/Prasad-pardeshi6002/WebTester-Selenium-Java.git**



**2. Open the project folder:**



&#x20;  **cd WebTester-Selenium-Java**



**3. Run the application:**



&#x20;  **./mvnw spring-boot:run**



&#x20;  **On Windows:**



&#x20;  **.\\mvnw.cmd spring-boot:run**



**4. Open your browser:**



&#x20;  **http://localhost:8080**
